## Resumen

Utiliza la CLI independiente para generar un objeto, campo, regla de validación, función lógica o componente de front:

```bash
integracore app add
integracore app add object --name invoice --name-plural invoices --no-input
integracore app add field --name amount --type NUMBER --object <object-uuid> --no-input
integracore app add validation-rule --name invoice-has-amount --object <object-uuid> --no-input
integracore app add logic-function --name send-invoice --no-input
integracore app add front-component --name invoice-panel --no-input
```

Sin indicadores, las terminales interactivas solicitan los valores faltantes. Para scripts y agentes, proporcione los campos obligatorios y use `--no-input` o `--json`.

La generación de objetos también puede crear una vista, un elemento de navegación y un diseño de página de registro:

```bash
integracore app add object --name invoice --name-plural invoices \
  --create-view --create-navigation-menu-item --create-page-layout --no-input
```

Para otros tipos de entidad, escriba el archivo `define*` correspondiente usando `integracore-sdk/define` y un UUID v4 válido. Ejecute `integracore app typecheck` y `integracore app plan` antes de sincronizar.

`--path` selecciona el directorio de la aplicación, no una carpeta de salida personalizada. Ejecute `integracore app add --help` para ver las opciones compatibles.
