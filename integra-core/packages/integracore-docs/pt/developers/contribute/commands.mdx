---
title: Comandos
description: Comandos úteis para desenvolver o IntegraCore.
---

Os comandos podem ser executados a partir da raiz do repositório usando `npx nx`. Use `npx nx run {project}:{command}` para direcionar explicitamente.

## Iniciando o aplicativo

```bash
npx nx start integracore-front          # Frontend dev server (http://localhost:3001)
npx nx start integracore-server         # Backend server (http://localhost:3000)
npx nx run integracore-server:worker    # Background worker
```

## Banco de Dados

```bash
npx nx database:reset integracore-server                          # Reset and seed database
npx nx run integracore-server:database:migrate:prod               # Run migrations
npx nx run integracore-server:database:migrate:generate --name <name> --type <fast|slow>  # Generate a migration
```

## Linting

```bash
npx nx lint:diff-with-main integracore-front    # Lint changed files (fastest)
npx nx lint:diff-with-main integracore-server
npx nx lint integracore-front --configuration=fix  # Auto-fix
```

## Verificação de tipos

```bash
npx nx typecheck integracore-front
npx nx typecheck integracore-server
```

## Testes

```bash
# Frontend
npx nx test integracore-front                          # Jest unit tests
npx nx storybook:build integracore-front               # Build Storybook
npx nx storybook:test integracore-front                # Storybook tests

# Backend
npx nx run integracore-server:test:unit                # Unit tests
npx nx run integracore-server:test:integration         # Integration tests
npx nx run integracore-server:test:integration:with-db-reset  # Integration with DB reset

# Single file (fastest)
npx jest path/to/test.test.ts --config=packages/{project}/jest.config.mjs
```

## GraphQL

```bash
npx nx run integracore-front:graphql:generate                        # Regenerate types
npx nx run integracore-front:graphql:generate --configuration=metadata  # Metadata schema
```

## Traduções

```bash
npx nx run integracore-front:lingui:extract   # Extract strings
npx nx run integracore-front:lingui:compile   # Compile translations
```

## Compilação

```bash
npx nx build integracore-shared   # Must be built first
npx nx build integracore-front
npx nx build integracore-server
```
