A CLI `yarn integracore` é a sua interface para tudo relacionado a aplicativos. Lista completa de comandos:

| Comando                                         | O que faz                                                                           | Documentado em                                                                                              |
| ----------------------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `dev`                                           | Monitora arquivos-fonte e sincroniza alterações em tempo real                       | [Início rápido](/pt/developers/extend/apps/getting-started/quick-start)                                        |
| `plan`                                          | Visualize as alterações de metadados sem aplicá-las                                 | [Sincronização e recuperação](/pt/developers/extend/apps/operations/sync-and-recovery#previewing-changes-plan) |
| `apply`                                         | Aplicar alterações de metadados após exibir o plano                                 | [Sincronização e recuperação](/pt/developers/extend/apps/operations/sync-and-recovery)                         |
| `dev:build`                                     | Compile o aplicativo e gere o cliente da API (`--tarball` para empacotar um `.tgz`) | [Publicação](/pt/developers/extend/apps/operations/publishing)                                                 |
| `dev:typecheck`                                 | Executar a verificação de tipos do TypeScript                                       | [Testes](/pt/developers/extend/apps/operations/testing)                                                        |
| `dev:add`                                       | Criar a estrutura inicial de uma nova entidade                                      | [Scaffolding](/pt/developers/extend/apps/getting-started/scaffolding)                                          |
| `dev:generate-client`                           | Regenerar o cliente da API tipado                                                   | esta página                                                                                                 |

Todo comando aceita `-r, --remote \<name>` para direcionar a um remoto específico em vez do padrão.

## Executando funções (`yarn integracore dev:function:exec`)

Execute manualmente uma função de lógica sem acioná-la via HTTP, cron ou evento de banco de dados:

```bash filename="Terminal"
# Execute by function name
yarn integracore dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn integracore dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn integracore dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the install and uninstall hooks
yarn integracore dev:function:exec --postInstall
yarn integracore dev:function:exec --preInstall
yarn integracore dev:function:exec --uninstall
```

## Visualizando logs de funções (`yarn integracore dev:function:logs`)

Transmita os logs de execução das funções de lógica do seu aplicativo:

```bash filename="Terminal"
# Stream all function logs
yarn integracore dev:function:logs

# Filter by function name
yarn integracore dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn integracore dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Isso é diferente de `yarn integracore docker:logs`, que mostra os logs do contêiner Docker. `yarn integracore dev:function:logs` mostra os logs de execução de funções do seu aplicativo a partir do servidor IntegraCore.
</Note>

## Gerando o cliente tipado (`yarn integracore dev:generate-client`)

Regenerar o cliente de API tipado (`integracore-client-sdk`) a partir do esquema do remoto ativo, sem compilar nem sincronizar um aplicativo. Use-o para obter um cliente tipado em qualquer projeto — como um serviço de backend em um repositório separado — que se comunica com a sua instância do IntegraCore:

```bash filename="Terminal"
# In your project (no IntegraCore app definition required)
yarn add integracore-sdk integracore-client-sdk

# Connect to the IntegraCore instance to generate the client from
yarn integracore remote:add

# Generate the typed client into node_modules/integracore-client-sdk
yarn integracore dev:generate-client
```

Em seguida, importe o cliente no seu código:

```typescript
import { CoreApiClient } from 'integracore-client-sdk/core';
```

Execute novamente o comando sempre que o seu modelo de dados for alterado para atualizar os tipos gerados.

<Note>
O cliente é gerado dentro de `node_modules`, portanto não é incluído no commit junto com o seu código. Execute `yarn integracore dev:generate-client` após cada instalação (por exemplo, em um script `postinstall` ou no CI).
</Note>

## Desinstalando um aplicativo (`yarn integracore app:uninstall`)

Remova seu aplicativo do espaço de trabalho ativo:

```bash filename="Terminal"
yarn integracore app:uninstall

# Skip the confirmation prompt
yarn integracore app:uninstall --yes
```

## Gerenciando remotos

Um **remoto** é um servidor IntegraCore ao qual seu aplicativo se conecta. Durante a configuração, o gerador de scaffold cria um para você automaticamente. Você pode adicionar mais remotos ou alternar entre eles a qualquer momento.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn integracore remote:add

# Connect to a local IntegraCore server (auto-detects port 2020 or 3000)
yarn integracore remote:add --local

# Add a remote non-interactively (useful for CI)
yarn integracore remote:add --url https://your-integracore-server.com --api-key $INTEGRA_API_KEY --as my-remote

# List all configured remotes
yarn integracore remote:list

# Set the active remote
yarn integracore remote:use <name>

# Check that the active remote's authentication is still valid
yarn integracore remote:status

# Remove a remote
yarn integracore remote:remove <name>
```

Suas credenciais são armazenadas em `~/.integracore/config.json`.
