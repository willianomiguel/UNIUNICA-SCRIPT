## Распространённые проблемы

* **Ошибки локальной среды**, проверьте `integracore local status` и `integracore local logs --no-follow`. Docker должен быть установлен и запущен с контекстом локального сокета. Добавьте `--test` для тестового экземпляра. При неудачном запуске его контейнер и данные сохраняются для диагностики.
* **Неверная версия Node** — требуется 24.5+ или 26.5+ (`engines.node: ^24.5.0 || ^26.5.1`). Проверьте с помощью `node -v`.
* **Yarn 4 отсутствует** — выполните `corepack enable` (в Node 26 сначала выполните `npm install -g corepack`).
* **Зависимости повреждены** — `rm -rf node_modules && yarn install`.
* **Пустой `yarn.lock`** — Сборка завершается ошибкой «yarn.lock is empty», когда файл блокировки существует, но не содержит данных; выполните `yarn install`, чтобы пересоздать его.
* **Ошибки `integracore-sdk` после обновления до v2.8.0** — он был перенесен из `dependencies` в `devDependencies` в v2.8.0. См. [Структура проекта → Зависимости](/ru/developers/extend/apps/getting-started/project-structure#dependencies).
* **`integracore app build` предупреждает о `integracore-client-sdk` в разделе `dependencies`** — он предоставляется IntegraCore во время выполнения, поэтому его следует перенести в `devDependencies` рядом с `integracore-sdk`. См. [Структура проекта → Зависимости](/ru/developers/extend/apps/getting-started/project-structure#dependencies).
